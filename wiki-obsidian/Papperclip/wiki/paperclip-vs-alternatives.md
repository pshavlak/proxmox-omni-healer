# Paperclip vs Альтернативы

## Чем Paperclip НЕ является

| Не это | Потому что |
|--------|-----------|
| Chatbot | У агентов работа, а не чат |
| Agent framework | Мы не учим строить агентов, мы учим управлять компанией из них |
| Workflow builder | Нет drag-and-drop pipelines. Моделируем компании |
| Prompt manager | Агенты приносят свои промпты |
| Single-agent tool | Если у тебя 1 агент — Paperclip не нужен |
| Code review tool | Оркестрация, не PR |

## Проблемы, которые решает

| Без Paperclip | С Paperclip |
|--------------|-------------|
| 20 вкладок Claude Code, потеря контекста | Тикетная система, threaded conversations |
| Ручной сбор контекста | Контекст течёт от задачи через проект к целям компании |
| Конфиги разбросаны | Оргструктуры, тикеты, governance из коробки |
| Runaway loops на сотни долларов | Cost tracking, бюджеты, throttling |
| Ручной запуск рутины | Heartbeats по расписанию |
| Идея → найти репо → запустить → babysit | Добавил задачу → агент работает → управление проверяет |
