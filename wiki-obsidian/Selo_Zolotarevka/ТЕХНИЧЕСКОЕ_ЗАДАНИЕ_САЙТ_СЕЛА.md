# Техническое задание на разработку неофициального сайта-портала села

## 1. Общие сведения

| Параметр | Значение |
|----------|----------|
| **Тип проекта** | Информационный портал, сайт сообщества села |
| **Целевая аудитория** | Жители села, бывшие земляки, гости и потенциальные туристы |
| **Главная задача** | Объединить информацию о ключевых организациях села, освещать местные события и спортивные достижения |
| **Рекомендуемая CMS** | WordPress (бесплатный, гибкая система прав доступа) |

---

## 2. Структура разделов и навигация

### 2.1. Главная страница

Общая лента новостей, важные объявления, виджет погоды.

### 2.2. Организации села (выпадающее меню ▾)

#### 2.2.1. Школа
- Новости классов
- Расписание автобуса
- Достижения учеников

#### 2.2.2. Детский сад
- Жизнь групп
- Полезные советы родителям
- Фотоотчеты

#### 2.2.3. Совхоз / Предприятие
- История
- Вакансии
- Производимая продукция
- Контакты

### 2.3. Спорт (выпадающее меню ▾)

#### 2.3.1. Футбольная команда
- Состав команды
- Расписание матчей
- Турнирная таблица
- Фото с игр

#### 2.3.2. Другие секции (опционально)
- Волейбол
- Шахматы
- Иные виды спорта

### 2.4. Жизнь села (выпадающее меню ▾)

#### 2.4.1. История и выдающиеся земляки
#### 2.4.2. Дом Культуры
- Афиша праздников
- Кружки и секции

#### 2.4.3. Доска объявлений
- Куплю / Продам
- Услуги местных мастеров

### 2.5. Медиа
- Общая фото- и видеогалерея села

---

## 3. Требования к дизайну и интерфейсу

### 3.1. Главная страница

| Элемент | Описание |
|---------|----------|
| **Визуальный стиль** | Дружелюбный, природные или современные светлые тона |
| **Баннер** | Крупный панорамный вид села |
| **Бенто-сетка (плитки)** | Блок быстрых ссылок на подразделения с яркими иконками или фото (например: плитка «Школа» с фото здания, плитка «Футбольный клуб» с эмблемой команды) |
| **Виджет матчей** | На видном месте блок: «Следующая игра ФК [Название]: Дата, время, соперник» |

### 3.2. Выпадающее меню (Мега-меню)

При наведении на пункт «Организации» открывается аккуратное меню, где у каждого подпункта есть небольшая иконка:

| Подпункт | Иконка |
|----------|--------|
| Школа | 📚 Книжка |
| Детский сад | 🧸 Игрушка |
| Совхоз | 🌾 Колосок |

## 4. Функциональные требования по блокам

### 4.1. Школа и Детский сад
- Возможность для учителей/воспитателей легко загружать фотографии с утренников и линеек.

### 4.2. Совхоз
- Блок **«Гордость села»** — рассказы о передовиках производства и ветеранах труда.

### 4.3. Футбольная команда
- **Информер прошедшего матча** — счёт, кто забил голы.
- **Профили игроков** — фото, позиция на поле (вратарь, нападающий и т.д.).

### 4.4. Интерактив
- **Блок «Предложить новость»** — чтобы жители сами присылали фото и истории.
- **Комментарии под новостями** — с премодерацией для защиты от спама.

## 5. Техническая реализация

### 5.1. Движок (CMS)

**Рекомендация: WordPress**

**Обоснование:**
- Бесплатный и с открытым исходным кодом
- Гибкая система ролей и прав доступа:
  - Тренер футбольной команды → обновляет страницу спорта
  - Завуч школы → наполняет школьный раздел
  - Воспитатель детсада → загружает фотоотчёты
- Большое количество готовых тем и плагинов
- Простота в обслуживании и масштабировании

### 5.2. Рекомендуемые плагины WordPress

| Назначение | Рекомендуемый плагин |
|------------|---------------------|
| Мега-меню | **Max Mega Menu** или **UberMenu** |
| Галерея | **NextGEN Gallery** или **Modula** |
| Календарь событий | **The Events Calendar** |
| Турнирная таблица | **Football Pool** или кастомный тип записи |
| Комментарии с премодерацией | Встроенная функция WordPress |
| Форма «Предложить новость» | **WPForms** или **Contact Form 7** |
| Погода | **WP Wunderground** или **Weather Atlas** |
| Доска объявлений | **Classifieds** или кастомный тип записи |

### 5.3. Хостинг

| Параметр | Рекомендация |
|----------|--------------|
| **Хостинг** | Любой PHP-хостинг с поддержкой MySQL (например, Beget, Timeweb, Reg.ru) |
| **PHP** | Версия 8.0+ |
| **База данных** | MySQL 5.7+ или MariaDB 10.3+ |
| **SSL-сертификат** | Обязательно (Let's Encrypt — бесплатно) |

## 6. Структура базы данных (WordPress)

Используются стандартные таблицы WordPress + кастомные типы записей:

| Тип записи | Назначение |
|------------|------------|
| `post` (стандартные) | Новости, объявления |
| `school_news` | Новости школы |
| `kindergarten_news` | Новости детского сада |
| `farm_production` | Продукция совхоза |
| `farm_vacancies` | Вакансии совхоза |
| `sports_team` | Профили игроков |
| `sports_match` | Матчи и результаты |
| `bulletin_board` | Доска объявлений |
| `gallery` | Медиа-галерея |

---

## 7. Роли и права доступа

| Роль | Доступ |
|------|--------|
| **Администратор** | Полный доступ ко всем разделам |
| **Редактор школы** | Публикация новостей школы и детсада |
| **Редактор спорта** | Управление разделом футбола и спорта |
| **Редактор совхоза** | Управление разделом предприятия |
| **Модератор** | Премодерация комментариев и предложенных новостей |
| **Автор** | Предложение новостей (без права публикации) |

---

## 8. Этапы разработки

| Этап | Описание | Ориентировочный срок |
|------|----------|---------------------|
| **1. Установка и настройка** | Установка WordPress, выбор и кастомизация темы, базовые плагины | 2–3 дня |
| **2. Структура разделов** | Создание рубрик, кастомных типов записей, настройка мега-меню | 2 дня |
| **3. Главная страница** | Вёрстка бенто-сетки, баннера, виджета матчей и погоды | 2–3 дня |
| **4. Наполнение разделов** | Школа, детсад, совхоз, спорт, жизнь села, медиа | 3–5 дней |
| **5. Интерактив** | Форма «Предложить новость», комментарии, доска объявлений | 1–2 дня |
| **6. Права доступа** | Настройка ролей и разграничение прав | 1 день |
| **7. Тестирование** | Проверка всех функций, адаптивность, скорость загрузки | 2 дня |
| **8. Запуск** | Перенос на боевой хостинг, финальные настройки | 1 день |

**Итого ориентировочный срок разработки:** 2–3 недели.
