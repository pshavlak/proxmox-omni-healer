# SEO: задача — предоставить ссылку на запущенный сайт

## Описание задачи

Для проведения SEO-оптимизации (плагин Yoast SEO / Rank Math, карта сайта, мета-теги, анализ скорости) **требуется ссылка на запущенный сайт в продакшене**.

|На текущем этапе сайт разворачивается на новом сервере (`31.56.208.248`) с доменом `золотаревка.рф`. Локальный IP контейнера: `192.168.1.64`. Что позволит:
- Провести SEO-аудит (скорость, Core Web Vitals)
- Установить и настроить SEO-плагины в боевом режиме
- Проверить индексацию в поисковых системах
- Настроить Google Search Console / Яндекс.Вебмастер
- Сгенерировать и проверить XML Sitemap
- Настроить Open Graph / Twitter Cards для шаринга в соцсетях
- Выполнить проверку адаптивности на реальных устройствах

## Критерий готовности к SEO

- [ ] Зарегистрирован домен (рекомендация: Beget, Timeweb, Reg.ru)
- [ ] Сайт перенесён на боевой хостинг
- [ ] Настроен SSL-сертификат (Let's Encrypt)
- [ ] Сайт доступен по HTTPS
- [ ] Предоставлена ссылка вида `https://example.com`

## Что делать после запуска

1. Установить и настроить SEO-плагин (Yoast SEO или Rank Math)
2. Сгенерировать XML Sitemap
3. Зарегистрировать сайт в Google Search Console и Яндекс.Вебмастер
4. Настроить мета-теги (title, description, OG) для каждой страницы
5. Проверить скорость через PageSpeed Insights
6. Настроить хлебные крошки и внутреннюю перелинковку
7. Проверить адаптивность и Core Web Vitals
