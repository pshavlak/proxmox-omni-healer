# LLM Wiki — Сайт села Золотаревка

Этот wiki поддерживается LLM-агентом по методологии Karpathy's LLM Wiki.

## Структура

- **`sources/`** — исходные документы (read-only, не редактировать)
- **`*.md`** — страницы wiki
- **`site/`** — код сайта (HTML/CSS/JS)
- **`wordpress/`** — WordPress mu-plugins и темы
- **`index.md`** — каталог всех страниц с описаниями
- **`log.md`** — хронология изменений (что, когда, почему)

## Операции

### Ingest
1. Положи файл в `sources/`
2. Прочти и осмысли содержание
3. Обсуди ключевые моменты с пользователем
4. Интегрируй: создай/обнови страницы, проставь `[[вики-ссылки]]`
5. Запиши в `log.md`

### Query
- Сначала просмотри `index.md` и релевантные страницы
- Отвечай с ссылками на страницы wiki (`[[страница]]`)
- Если ответ требует нового знания — создай страницу

### Lint
Периодически проверяй:
- Нет ли страниц без входящих ссылок
- Нет ли устаревших утверждений
- Нет ли противоречий между страницами
- Обновляй `index.md`

### Ответы
- Отвечай кратко, ёмко, по-русски
- Используй `[[вики-ссылки]]` везде
- При изменениях — обновляй `log.md`
