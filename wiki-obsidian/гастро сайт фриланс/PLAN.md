# План создания лендинга врача гастроэнтеролога-диетолога

**Заказ:** [fl.ru — Создание лендинга для врача гастроэнтеролога-диетолога (онлайн-консультации, коррекция веса)](https://www.fl.ru/projects/5507163/sozdanie-lendinga-dlya-vracha-gastroenterologa-dietologa-onlayn-konsultatsii-korrektsiya-vesa.html)

---

## Технологический стек

| Элемент         | Решение                                         |
|-----------------|-------------------------------------------------|
| Вёрстка         | Чистый HTML5 + CSS3 + ванильный JavaScript       |
| CSS-фреймворк   | Tailwind CSS (CDN)                               |
| Шрифт            | Roboto (Google Fonts CDN)                        |
| Иконки           | Font Awesome CDN                                 |
| Формы            | PHP-скрипт → email + Telegram Bot                |
| Капча            | Honeypot (скрытое поле) + опционально reCAPTCHA   |
| Аналитика        | Яндекс.Метрика                                   |
| Лайтбокс         | Ванильный JS (дипломы/сертификаты)               |

> **Примечание:** простая вёрстка без фреймворков и сборщиков (по требованию заказчика). Вопрос хостинга (статика vs PHP) уточнить у заказчика — если статика, заменить PHP-обработчик на Netlify Forms или Formspree.

## Страницы и их содержимое

### 1. Главная страница (`index.html`)

| Секция | Описание |
|--------|----------|
| **Шапка** | Логотип, меню (Услуги, О враче, Отзывы, Контакты), кнопка «Записаться онлайн в клинике» |
| **Hero** | ФИО врача, специализации, УТП, краткий список услуг (3 блока-ссылки), кнопка «Записаться» |
| **О враче (кратко)** | Фото + 2-3 предложения, ссылка на полную страницу «О враче» |
| **Три направления** | Карточки с иконками: Эндоскопия, Гастроэнтерология онлайн, Диетология. На каждой — кнопка «Подробнее» |
| **Отзывы** | 2-3 цитаты + кнопка «Все отзывы» |
| **Форма записи** | Имя, телефон/Telegram, комментарий |
| **Подвал** | Копирайт, ссылки на Политику конфиденциальности и Договор оферты, юридическое предупреждение |

### 3. Гастроэнтерология онлайн (`gastroenterologiya.html`)

- Список услуг с ценами:

| Услуга | Цена |

- У каждой услуги — кнопка «Заказать»
- Как проходит консультация (3-4 шага с иконками)

### 4. Питание и диетология (`dietologiya.html`)

- Описание направления (индивидуальные планы питания, протоколы при патологиях ЖКТ и дефицитах; без назначения БАДов и лекарств)
- **Планы питания:**

| Услуга | Цена |
|--------|------|
| На 14 дней | 2 500 ₽ |
| На 30 дней (подробный протокол) | 4 000 ₽ |

- **Лечебные протоколы:**

| Услуга | Цена |
|--------|------|
| При ГЭРБ, СРК, НАЖБП, гастрите | 2 000 ₽ |
| При дефицитах (железо, B12, D, кальций) | 3 000 ₽ |

- У каждой услуги — кнопка «Заказать»

### 5. О враче (`o-vrache.html`)

- Фото врача
- Образование и опыт (ключевые этапы, кратко)
- Дипломы и сертификаты (миниатюры с возможностью увеличения — лайтбокс)
- Ключевые цифры (опыт работы, количество процедур, пациентов)
- Философия / подход к работе (2-3 предложения от первого лица)
- Ссылки на блоги: Telegram, соцсети, Дзен

### 6. Отзывы (`otzyvy.html`)

- Список отзывов (минимум 5) с разных платформ
- Каждый отзыв: цитата, город, рейтинг (звёзды)

### 7. Контакты (`kontakty.html`)

- Форма записи: имя, телефон/Telegram, выбор услуги (выпадающий список из трёх направлений), комментарий
- Кнопка «Отправить заявку»
- Телефон клиники для очного приема (кликабельный)
- Ссылка на Telegram
- Адреса клиник

### 8. Служебные страницы

- `privacy.html` — Политика конфиденциальности
- `offer.html` — Договор оферты

## Функциональные требования

| Требование | Реализация |
|------------|------------|
| Адаптив под мобильные и планшеты | Tailwind responsive-классы (sm/md/lg/xl) |
| Форма заявки отправляет данные на email и дублирует в Telegram | PHP-скрипт `send-form.php` → `mail()` + Telegram Bot API |
| Кнопки мессенджеров открывают чат с предзаполненным текстом | WhatsApp: `https://wa.me/...`, Telegram: `https://t.me/...` |
| Яндекс.Метрика | Код в `<head>` |
| Защита от спама | Honeypot (скрытое поле `name="_honey"`), опционально reCAPTCHA v3 |
| Дизайн: светлые тона, контрастные кнопки | CSS-переменные, Tailwind-кастомизация |
| Шрифт Roboto | Google Fonts CDN |
| Иконки | Font Awesome CDN |

## Поэтапный план реализации
