# Hysteia2 VPN Wiki

Персональная база знаний по настройке и эксплуатации Hysteria2 VPN.

## Начало
- Просмотри [[index]] для навигации по страницам
- Добавляй источники в `sources/` для загрузки новых знаний
- Смотри [[log]] для истории изменений

## Что это?
Wiki поддерживается LLM-агентом по методологии [Karpathy LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).
