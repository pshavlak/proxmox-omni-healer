# Xray Server

**Xray** — прокси-платформа следующего поколения (форк V2Ray), работающая на [[cascade-server]] в Хельсинки. Выполняет две функции: приём VLESS+REALITY подключений и предоставление SOCKS5-прокси для каскада с [[hysteria-2-server]].

## Роль в инфраструктуре

Xray — центральный узел на каскадном сервере:

1. **SOCKS5 (`:18443`)** — принимает каскадный трафик от Hysteria 2 сервера
2. **VLESS + REALITY (`:443`)** — самостоятельный вход для 26 пользователей

Трафик из SOCKS5 и VLESS направляется в [[wireproxy]] для выхода через Cloudflare WARP.

## Технические детали

| Параметр | Значение |
|----------|----------|
| **VLESS порт** | `:443` |
| **Транспорт** | REALITY (TLS без сертификата) |
| **Пользователей VLESS** | 26 |
| **SOCKS5 порт** | `:18443` |
| **Управление** | X-UI панель |

## Дополнительно

На сервере также установлены:
- **X-UI** — веб-панель управления Xray (не путать с Flask-панелью Hysteria)
- **CrowdSec** — IDS/IPS для защиты от атак
- **3dp-manager** — управление 3D-принтером (в Docker)
