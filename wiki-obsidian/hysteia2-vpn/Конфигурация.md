# Конфигурация Hysteria

**Файл:** `config.yaml`
**Путь на сервере:** `/etc/hysteria/config.yaml`

## Параметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| `listen` | `:8443` | QUIC-порт (с 29.05.2026, был :443) |
| `tls.cert` | Let's Encrypt fullchain | SSL-сертификат |
| `auth.type` | `http` | Авторизация через HTTP-бэкенд |
| `auth.http.url` | `http://127.0.0.1:8081/auth` | Flask-ендпоинт |
| `resolver` | Яндекс DNS `77.88.8.8:53` | DNS-резолвер |
| `sniff.enable` | `true` | Сниффинг SNI для ACL |
| `logLevel` | `debug` | Уровень логирования |

## Outbound'ы (каскад)

Два outbound:
- **`exit_socks`** — SOCKS5 на Финляндию (`193.164.155.153:18443`)
- **`direct`** — прямой выход

До 16.04.2026 работал без каскада. См. [[Каскад]].

## Смена порта (29.05.2026)

**Причина:** UDP 443 блокируется провайдерами (DPI). Hysteria перенесён на порт 8443.

**Настройка:**
```bash
# iptables редирект для старых клиентов
iptables -t nat -A PREROUTING -p udp --dport 443 -j REDIRECT --to-port 8443

# Сохранение правила (через iptables-persistent)
apt install iptables-persistent
netfilter-persistent save
```

Старые клиенты (с портом 443) продолжают работать через iptables. Новым рекомендуется порт 8443.

## TLS-сертификат

Сертификат Let's Encrypt обновляется certbot'ом. Hysteria использует путь `/etc/letsencrypt/live/hist.yupiterpro.ru/` (реальные файлы, скопированные из `-0001`). Установлен post-hook для автоматического копирования при продлении:

```bash
/etc/letsencrypt/renewal-hooks/post/copy-to-hysteria.sh
```

Nginx использует `/etc/letsencrypt/live/hist.yupiterpro.ru-0001/` (symlinks, обновляется certbot'ом).
