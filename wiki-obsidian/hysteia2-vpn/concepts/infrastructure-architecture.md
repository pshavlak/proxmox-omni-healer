# Infrastructure Architecture

Общая архитектура VPN-инфраструктуры. Двухуровневая система с основным Hysteria 2 сервером и каскадным SOCKS5 сервером для разделения и оптимизации трафика.

## Схема трафика

```
Клиенты (19 пользователей)
  │
  ▼
┌─────────────────────────────────────┐
│  Hysteria 2 Server                  │
│  62.113.105.38:8443                 │
│  hist.yupiterpro.ru                 │
│                                     │
│  1. ACL проверка (acl.txt)          │
│     ├─ Российские сайты ───── direct │
│     └─ Иностранные сайты ── SOCKS5  │
└──────────┬──────────────────────────┘
           │ SOCKS5 :18443
           ▼
┌─────────────────────────────────────┐
│  Cascade Server (Хельсинки)         │
│  193.164.155.153                    │
│                                     │
│  Xray                               │
│  ├─ SOCKS5 :18443 (из Hysteria)     │
│  └─ VLESS+REALITY :443 (26 польз.)  │
│         │                           │
│         ▼                           │
│  WireProxy (127.0.0.1:40000)        │
│  WireGuard туннель                  │
│         │                           │
│         ▼                           │
│  Cloudflare WARP                    │
│  engage.cloudflareclient.com:2408   │
└──────────┬──────────────────────────┘
           │
           ▼
        Интернет
```

## Ключевые принципы

1. **Разделение трафика** — российские ресурсы выходят напрямую с Hysteria сервера (минимальная задержка), иностранные — через каскад в Хельсинки (обход блокировок)
2. **Двухуровневое шифрование** — QUIC (Hysteria) + TLS (Xray REALITY) + WireGuard (WARP)
3. **Маскировка** — Hysteria 2 маскируется под HTTP/3, Xray REALITY — под обычный HTTPS
4. **Анонимизация** — Cloudflare WARP скрывает реальный IP сервера выхода

## DNS

Яндекс DNS (`77.88.8.8:53`) используется на Hysteria сервере как для UDP, так и для TCP резолвинга (таймаут 4s). Выбран, вероятно, для надёжного резолвинга российских доменов внутри РФ.
