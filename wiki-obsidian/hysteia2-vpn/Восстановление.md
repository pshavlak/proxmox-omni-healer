# Восстановление на новом сервере

## Порядок действий

1. **Установка Hysteria** — `bash <(curl -fsSL https://get.hy2.sh/)`
2. **Создание пользователя** — `useradd -r -s /bin/false hysteria`
3. **Директории** — `/etc/hysteria`, `/var/lib/hysteria`
4. **SSL-сертификат** — `certbot certonly --nginx -d hist.yupiterpro.ru`
5. **Копирование конфигов** — `config.yaml`, `users.json`, `acl.txt`, `passwords.txt`
6. **Systemd** — копировать unit'ы, `daemon-reload`, `enable`, `start`
7. **Nginx** — скопировать сайт, `nginx -t`, `restart`
8. **Веб-панель** — `mkdir -p /opt/hysteria-manager`, скопировать `app.py` и `hysteria-users.sh`
9. **Fail2ban** (рекомендуется)

```ini
[DEFAULT]

findtime = 10m
maxretry = 3

[sshd]
enabled = true

[recidive]
enabled = true
bantime = -1
findtime = 1d
maxretry = 3
```

## После восстановления

1. Перевыпустить SSL-сертификаты (не включены в бэкап)
2. Установить certbot hook: `/etc/letsencrypt/renewal-hooks/post/copy-to-hysteria.sh`
3. Настроить iptables редирект UDP 443→8443:
   ```bash
   apt install iptables-persistent
   iptables -t nat -A PREROUTING -p udp --dport 443 -j REDIRECT --to-port 8443
   netfilter-persistent save
   ```
4. Проверить через `curl --socks5-hostname` что каскад работает
5. Проверить что российские сайты идут напрямую
