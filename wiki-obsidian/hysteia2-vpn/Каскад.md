# Каскад (SOCKS5 Cascade)

**Добавлен:** 16.04.2026
**Тип:** SOCKS5
**Узел:** `193.164.155.153:18443`
**Логин:** `cascade`
**Локация:** Финляндия, Хельсинки

## Назначение

Перенаправление трафика на зарубежные ресурсы через финский exit node. Российские сайты идут напрямую (см. [[ACL-правила]]).

## Конфигурация в outbounds

```yaml
outbounds:
  - name: exit_socks
    type: socks5
    socks5:
      addr: 193.164.155.153:18443
      username: cascade
      password: d17ed2425d8b1c37b5ee00ed4e28cd0b
  - name: direct
    type: direct
```

## Проверка работы

```bash
# Через каскад
curl --socks5-hostname cascade:d17ed2425d8b1c37b5ee00ed4e28cd0b@193.164.155.153:18443 https://api.ipify.org

# Напрямую
curl https://api.ipify.org
```

Должны показывать разные IP.
