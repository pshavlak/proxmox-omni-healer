# Архитектура

## Схема

```
Внешний мир → hist.yupiterpro.ru:443 (TCP) / :8443 (UDP)
                     ↓
              Nginx (TCP 443)
              ├── /* → сайт-заглушка
              └── /44169d2dba4d0fd5/ → proxy_pass → Flask :8081
              
Hysteria (UDP 8443, + iptables редирект 443→8443)
  → HTTP Auth → Flask :8081/auth
  → ACL проверка:
    ├── geoip:ru + geosite:category-ru → direct
    ├── российские домены (явный список) → direct
    └── всё остальное → SOCKS5 cascade → 193.164.155.153:18443
                      → Финляндия, Хельсинки
```

Hysteria слушает на UDP 8443. Для совместимости со старыми клиентами настроен iptables редирект с UDP 443 → 8443.
Nginx слушает на TCP 443 и не пересекается с Hysteria (TCP vs UDP).

## Компоненты

| Компонент | Роль | Порт |
|-----------|------|------|
| [[Hysteria2]] | VPN-сервер | 8443 (UDP/QUIC), + iptables 443→8443 |

| [[Веб-панель Manager]] | Flask-панель управления | 8081 (loopback) |
| [[Каскад]] | SOCKS5 exit node | 193.164.155.153:18443 |
| Яндекс DNS | Резолвер | 77.88.8.8:53 |

## DNS
Резолвер — Яндекс DNS (`77.88.8.8`). До 16.04.2026 использовался Google DNS (`8.8.8.8`).
