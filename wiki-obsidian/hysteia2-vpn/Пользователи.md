# Пользователи

**Файл:** `users.json`
**Путь на сервере:** `/etc/hysteria/users.json`

## Формат

```json
{
  "username": "base64_password"
}
```

Пароль — `token_urlsafe(16)` (генерируется [[Веб-панель Manager]] или [[CLI-скрипт]]).

## Аутентификация

Hysteria шлёт POST-запрос на `http://127.0.0.1:8081/auth` с паролем пользователя. Flask проверяет наличие пароля в `users.json`.

См. [[Веб-панель Manager]].
