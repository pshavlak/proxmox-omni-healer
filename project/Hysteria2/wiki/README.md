# Hysteria2 Project Wiki

Локальная wiki для каскадного VPN-проекта Hysteria2.

Принцип: README остаётся инструкцией восстановления, а wiki хранит живой контекст проекта: архитектуру, фактическое состояние серверов, операции, риски и историю проверок.

## Как пользоваться

1. Начинай с `index.md`.
2. Для свежей истории смотри `log.md`.
3. Для фактов по серверам и портам смотри `pages/architecture.md` и `pages/servers.md`.
4. После проверок или изменений обновляй `log.md` и затронутые страницы.

## Структура

- `index.md` - карта wiki.
- `log.md` - хронология действий.
- `schema.md` - правила ведения wiki.
- `pages/` - поддерживаемые страницы знаний.
- `raw/` - исходники и внешние источники, которые не надо переписывать.
