# Wiki Schema

Эта wiki создана по идее LLM Wiki: LLM поддерживает структурированные markdown-страницы, а не каждый раз заново извлекает смысл из сырых файлов.

## Layers

- `raw/` - исходники и ссылки. Не переписывать без причины.
- `pages/` - поддерживаемые страницы знаний. Обновлять при изменении фактов.
- `index.md` - карта актуальных страниц и ключевых фактов.
- `log.md` - append-only хронология действий.

## Page Rules

- Пиши коротко и проверяемо.
- Для серверных фактов указывай дату проверки.
- Для команд указывай, где они выполняются: local, main server, cascade server.
- Секреты редактируй как `[redacted]`.
- Если факт не проверен в текущей сессии, помечай как `from README` или `unverified`.

## Update Rules

- После production check добавь запись в `log.md`.
- После изменения server-side файлов обнови `pages/operations.md` и `pages/security.md`, если применимо.
- После изменения портов, доменов или маршрутизации обнови `index.md`, `pages/architecture.md`, `pages/servers.md`, `README.md`.
- Не меняй `raw/` как рабочие заметки; добавляй новые source notes отдельными файлами.

## Lint Checklist

- Нет противоречий по портам `443` и `8443`.
- Нет секретов в открытом тексте, кроме уже существующих исходных конфигов проекта.
- Каждая важная операция есть в `log.md`.
- `index.md` ведет на все важные страницы.
