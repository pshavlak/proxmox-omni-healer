# Legacy Archive

Архив создан 2026-06-26 при подготовке FastAPI-версии к переносу на сервер.

Содержимое:

- `wordpress/` — старая WordPress-реализация и MU-плагины.
- `sketches/` — HTML-прототипы админ-панели.
- `root-docs/` — старые ТЗ, аудиты, планы и WordPress `.env`.
- `site-static/` — прежняя статическая версия из `site/`.
- `generated/` — локальные `.venv`, вложенный `.git`, `__pycache__`, `.DS_Store`.

Для деплоя использовать `site/` из корня проекта, не этот архив.
