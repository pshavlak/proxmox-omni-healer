# Changelog

## [4.1.0] — 2026-07-11 — Стабилизация и исправление доступа

### Исправлено
- **Инфраструктура**: Исправлен путь деплоя с `/opt/zolotarevka` на `/var/www/zolotarevka-fastapi` (согласно реальной архитектуре сервера).
- **Связь**: Восстановлен SSH Reverse Tunnel между VPS (31.56.208.248) и локальным сервером (192.168.1.64) через `reverse-tunnel.service`.
- **Админ-панель**: Реализовано полноценное модальное окно создания пользователя с полями «Пароль» и «Подтверждение пароля».
- **Авторизация**: Сброшены пароли администраторов в БД для восстановления доступа после миграций.
- **Окружение**: Исправлена проблема «Internal Server Error» путем принудительного пересоздания `.venv` и исправления прав доступа (chown root:root).
