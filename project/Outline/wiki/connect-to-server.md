# 🔌 Подключение к серверу

**Сервер:** `95.182.98.178`
**Пользователь:** `root`
**Хостнейм:** `paris`

---

## 1️⃣ Подключение по SSH-ключу (рекомендуется)

Ключ уже настроен. Просто выполни:

```bash
ssh root@95.182.98.178
```

### Если ключ потерян — настроить заново

**Шаг 1.** Сгенерировать ключ (если нет):

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""
```

**Шаг 2.** Скопировать на сервер:

```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@95.182.98.178
```

**Шаг 3.** Подключиться:

```bash
ssh root@95.182.98.178
```

```bash

```

> ⚠️ Пароль лучше сохранить в менеджере паролей, а не в открытом виде.

---

## 3️⃣ Полезные флаги SSH

| Флаг | Описание |
|------|----------|
| `-v` | Подробный вывод (отладка) |
| `-i ~/.ssh/mykey` | Указать конкретный ключ |
| `-p 2222` | Другой порт (если не 22) |
| `-o BatchMode=yes` | Без интерактива (для скриптов) |

---

## 4️⃣ Быстрая проверка

```bash
ssh -o BatchMode=yes root@95.182.98.178 "hostname && uptime"
# Должно вернуть: paris и аптайм
```
