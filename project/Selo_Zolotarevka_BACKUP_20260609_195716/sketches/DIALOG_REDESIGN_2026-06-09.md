## Решения и изменения

### 1. Новая архитектура админ-панели

Вместо плоского списка — **единый каталог управления** с разделами:

| Раздел | Описание |
|--------|----------|
| 📊 **Панель управления** | Дашборд, статистика, статусы страниц, «Опубликовать всё» |
| 📝 **Контент сайта** | Древовидная структура страниц с возможностью добавлять/удалять/редактировать разделы и подразделы |
| 🖼️ **Медиа-центр** | Галерея (CPT), Видео (CPT zolo_video), Медиатека WP |
| 👥 **Пользователи и роли** | 5+ ролей, управление доступом к разделам, таблица пользователей |
| ⚙️ **Настройки сайта** | Соцсети, контакты, теглайн, SEO |

### 2. Динамические разделы и подразделы

- Раздел = пункт меню верхнего уровня
- Подраздел = вложенное подменю
- Каждый раздел/подраздел = самостоятельная страница
- Иерархия автоматически строит меню сайта
- При добавлении страницы — иерархический выбор расположения

### 3. Блочный конструктор страниц

Каждая страница собирается из блоков. Типы блоков:

| Тип | Что делает |
|-----|-----------|
| 🧱 Hero / Баннер | Заголовок, подзаголовок, фон (цвет/картинка), CTA-кнопка |
| 📝 Текст | HTML-текст с редактором |
| 🖼️ Изображение | Картинка с подписью и alt-текстом |
| 📸 Галерея | Сетка фото, настраиваемое количество колонок |
| 🎬 Видео | Вставка Rutube / VK Video по ссылке |
| 📊 Таблица | Строки и колонки, редактируемые заголовки |
| 🏗️ Карточки / Плитки | Два режима: ручной и авто из разделов сайта |
| 📄 Документы | PDF/DOC/XLS с иконками по типу |
| 📋 Форма | «Предложить новость» или «Обратная связь» |
| ➖ Разделитель | Визуальное разделение секций |

**Операции с блоками:** добавить, удалить, перемещать (⬆⬇), настраивать в модалке.

### 4. Карточки / Бенто-сетка — новый режим

**🌳 Автоматический режим (по умолчанию):**
- Карточки динамически подтягиваются из дерева разделов сайта
- При добавлении/удалении раздела — карточки обновляются автоматически
- Можно редактировать: URL картинки (или иконка по умолчанию), описание
- Поле «Все разделы →» (ссылка на ленту)

**✏️ Ручной режим:**
- Полный контроль: название, описание, ссылка, иконка/URL картинки

### 5. Пользователи и роли

- Динамическая таблица ролей с возможностью добавления/удаления
- При создании роли — чекбоксы с разделами из дерева страниц (автоматически синхронизируется)
- Дополнительные права: модерация комментариев, загрузка файлов, публикация без модерации
- Таблица пользователей с поиском и статусами

## Интерактивный режим работы

Использован workflow:
1. Схема в Excalidraw для визуализации структуры
2. Интерактивный HTML-прототип для обкатки UX

4. После утверждения — перенос в PHP mu-plugin

## Технические решения (для реализации)

### Структура данных для страниц
```php
// Опция для хранения дерева страниц
update_option('zolo_site_pages', [
  ['id' => 'school', 'name' => 'Школа', 'icon' => '📚', 'parent' => null, 'order' => 1, 'status' => 'published'],
  ['id' => 'school-news', 'name' => 'Новости школы', 'icon' => '📰', 'parent' => 'school', 'order' => 0, 'status' => 'published'],
]);
```

### Структура данных для блоков страницы
```php
// Опция для блоков конкретной страницы
update_option('zolo_page_blocks_' . $page_id, [
  ['id' => 'b1', 'type' => 'hero', 'name' => 'Баннер', 'config' => [...]],
  ['id' => 'b2', 'type' => 'cards', 'name' => 'Плитки', 'config' => ['auto_from_tree' => true, ...]],
]);
```

### Данные для ролей
```php
update_option('zolo_roles', [
  ['id' => 'school_editor', 'name' => 'Редактор школы', 'icon' => '📚', 'sections' => ['school', 'school-news'], 'caps' => [...]],
]);
```
