# Сценарная структура и narrative flow MVP

Дата: 2026-05-26
Issue: YUP-4

## 1. Цель сценария MVP
Сформировать понятный путь для трех основных аудиторий:
- житель села (быстро найти актуальные новости и объявления);
- семья с детьми (школа/детсад/расписания/фото);
- футбольный болельщик (ближайший матч, результаты, таблица).

Принцип MVP: сначала довести пользователя до полезного действия за 2-3 клика, затем углублять в тематические разделы.

## 2. Информационная роль главной страницы
Главная страница — маршрутизатор и витрина:
- Hero: эмоциональный вход и обещание ценности портала;
- Bento-сетка: 6 быстрых входов в ключевые разделы;
- Виджет ближайшего матча: регулярный повод возвращаться;
- Лента новостей: подтверждение, что сайт живой;
- CTA "Предложить новость": пользовательский вклад в контент.

## 3. Базовые пользовательские сценарии

### Сценарий A: Житель ищет важную информацию
1. Вход на главную.
2. Просмотр последних новостей.
3. Переход в "Жизнь села" или "Новости".
4. Чтение публикации.
5. Возврат на главную или переход к объявлениям.

Целевое действие: получить актуальную информацию без поиска по меню.

### Сценарий B: Родитель ищет школьную/дошкольную информацию
1. Вход на главную.
2. Переход по плитке "Школа" или "Детсад".
3. Просмотр новостей и полезных блоков (расписание, советы, фотоотчеты).
4. Оставить комментарий/вопрос (с премодерацией).

Целевое действие: быстро найти практическую информацию для семьи.

### Сценарий C: Болельщик следит за командой
1. Вход на главную.
2. Просмотр блока "Следующий матч".
3. Переход в раздел "Спорт".
4. Просмотр прошедшего матча, расписания, таблицы, состава.

Целевое действие: получить спортивную сводку в одном разделе.

### Сценарий D: Пользователь предлагает контент
1. Вход на главную или страницу новостей.
2. Клик по CTA "Предложить новость".
3. Заполнение формы (имя, контакт, текст, вложение).
4. Отправка на премодерацию.

Целевое действие: запустить регулярный UGC-поток для контентного роста.

## 4. Narrative flow по экранам

### Этап 1. Привлечение внимания
- Визуальный контекст села (hero, дружелюбная палитра).
- Короткое обещание: "новости, события, спорт, история".

### Этап 2. Выбор намерения
- Bento-сетка и мега-меню явно разделяют 3 кластера:
  - организации;
  - спорт;
  - жизнь села + медиа.

### Этап 3. Получение ценности
- Каждая страница раздела начинается с самого частого запроса:
  - школа: новости + расписание;
  - детсад: жизнь групп + советы;
  - спорт: результат + ближайшие игры + таблица;
  - совхоз: история + вакансии;
  - жизнь села: история + объявления.

### Этап 4. Вовлечение
- Комментарии под публикациями.
- Форма "Предложить новость".
- Медиа-галерея как социальное подтверждение участия жителей.

## 5. Контентный ритм MVP
Минимальная периодичность для ощущения "живого" портала:
- Новости: 2-3 публикации в неделю.
- Спорт: обновление после каждого матча.
- Школа/детсад: 1-2 обновления в неделю.
- Доска объявлений: обновление по мере поступления, ревизия 1 раз в неделю.

## 6. Критерии готовности сценарного MVP
MVP сценарий считается выполненным, если:
- пользователь из любой из 3 ключевых аудиторий доходит до целевого раздела за 2-3 клика;
- на главной есть явный вход в UGC-поток ("Предложить новость");
- в разделе "Спорт" есть полный минимальный цикл: следующий матч, прошедший матч, таблица;
- в разделе "Жизнь села" есть объявления и исторический блок;
- комментарии и форма отправки работают как вход в редакционную модерацию.

## 7. Что не входит в текущий MVP
- персонализация ленты;
- продвинутая фильтрация/поиск по всем материалам;
- автоматическая спортивная статистика из внешних API;
- полноценные пользовательские кабинеты.

Это оставляется на следующий этап после стабилизации базового контентного процесса.
