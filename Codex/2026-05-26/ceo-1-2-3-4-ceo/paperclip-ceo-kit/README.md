# Paperclip CEO Kit

Этот набор подготовлен под структуру `Paperclip`, где инструкции CEO обычно лежат в:

- `agents/ceo/SOUL.md`
- `agents/ceo/AGENTS.md`
- `agents/ceo/HEARTBEAT.md`
- `agents/ceo/TOOLS.md`

В комплект также добавлен файл:

- `agents/ceo/TEAM_PROMPTS.md`

Он содержит подробные промпты для агентов, которых CEO должен нанимать и координировать:

- Сценарист
- Ресерчер
- Контентмейкер
- Бэкендер
- Фронтендер
- Агент по безопасности

## Как применять в Paperclip

1. Откройте текущий экспорт/директорию вашей компании в Paperclip.
2. Замените или адаптируйте файлы `agents/ceo/*.md` содержимым из этого набора.
3. Используйте `TEAM_PROMPTS.md` как:
   - источник системных промптов для новых агентов;
   - шаблон для найма через CEO;
   - основу для постановки задач и критериев приёмки.

## Что умеет этот CEO

- Управляет проектом, а не делает работу руками.
- Делит работу на этапы и подэтапы.
- Нанимает агентов под конкретные функции.
- Требует от каждого агента:
  - подробный план;
  - рабочий промпт собственной роли;
  - список артефактов;
  - критерии готовности.
- Принимает результаты только по критериям.
- Раздаёт следующие задачи на основе утверждённого плана и уже выполненной работы.
